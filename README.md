# QUANTIX — Quantum Computing Club Website

Official website and interactive learning platform for **QUANTIX**, the Quantum Computing Club of **Shridevi Institute of Engineering & Technology (SIET)**, Tumakuru, Karnataka.

Developed in collaboration with **Dept. of Artificial Intelligence & Data Science**, **Dept. of Artificial Intelligence & Machine Learning**, and **AI Syntax Surge**.

---

## Features

- **Interactive 3D Bloch Sphere Lab:** Real-time 3D interactive quantum state vector simulator ($|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$). Supports mouse/touch 3D orbit, gate operations ($H$, $X$, $Z$, $S$), and projective measurement wavefunction collapse.
- **2-Qubit Circuit Playground:** Live interactive quantum wire simulator demonstrating quantum superposition and entanglement into an EPR Bell State ($|\Phi^+\rangle$), with 1024-shot simulation histogram.
- **Three Progressive Curriculum Tracks:**
  - *Track 01: Quantum Basics & Linear Algebra* (Hilbert spaces, qubits, Dirac bra-ket notation, logic gates)
  - *Track 02: Quantum Algorithms & NISQ Systems* (Grover's search, Shor's algorithm, VQE, QAOA)
  - *Track 03: Applications & Post-Quantum Frontiers* (Qiskit, PennyLane, Quantum ML, Lattice Cryptography)
- **Leadership & Faculty Mentorship Showcase:** Highlighting Faculty Mentor **Dr. Girish L**, President **Dipankar Chettri**, and the verified core team roster.
- **Events & Launch Timeline:** Orientation schedules, hands-on Qiskit workshops, and hackathon sprints.
- **Membership Application Portal:** Integrated onboarding modal with real-time validation and celebratory feedback.
- **Craft Floor Design Compliance:** Designed adhering to the [Impeccable](https://github.com/pbakaus/impeccable) design skill, eliminating generic AI slop, avoiding gradient text clichés, with custom-themed scrollbars and accessible color contrast.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
git clone https://github.com/Quantix-QML/Quantix-Website.git
cd Quantix-Website
npm install
```

### Local Development

```bash
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
npm run preview
```
